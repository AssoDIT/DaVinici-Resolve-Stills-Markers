User Guide – Burn-in Builder

1. Add a Burn-in Token

Click a metadata token in the left column to add it to the burn-in layout. Favorites are shown first. Click Show more to access the full token library. Use the search field to filter by name.

Click Custom to create a free-form text element using any combination of tokens.

2. Selection, Movement & Deletion

  • Click an element on the canvas to select it and show its properties.
  • Drag it on the canvas to reposition.
  • Use Position X / Y sliders for precise placement (0–100%).
  • Arrow keys move the selected token by 0.1% — hold Shift for 1% steps.
  • Right-click an element in the layout list to delete it.
  • Click Reset to remove all elements at once.

3. Custom Template

Use the Template field to build a composite line from multiple tokens:
%Scene / %Shot - %Take %Camera_#

Any %Key is replaced by its live metadata value. Combine tokens with any separator text you like.

4. Appearance

  • Font Size in points (pt) — scales with the 1080-line reference.
  • Text Color — pick any hex color.
  • Opacity — text transparency (0 = invisible, 1 = opaque).
  • BG Opacity — black background box behind the text (0 = no box).
  • Font — choose from system fonts or load a TTF/OTF file.
  • Bold — toggle bold weight.
  • Align — Left / Center / Right relative to the anchor point.

5. Exporting to Resolve

  • Send to Resolve — writes the preset directly into Resolve's SlatePresetList.xml. Reload Resolve's burn-in dialog to see it.
  • Export XML — downloads a .xml file you can import manually via Resolve's burn-in preset menu.
  • Enter a Preset name before exporting. If a preset with the same name already exists it will be replaced.
  • All Custom Text slots are written to the preset. Resolve 21+ supports more than 3 — versions prior to 21 only render the first 3 (Custom Text1/2/3).

6. Resolve Presets

Click Resolve Presets to browse all presets currently saved in Resolve. Expand a preset to see its elements, then click Import into layout to load it.

7. Ratio

The Ratio selector controls the delivery format bars overlaid on the canvas.

  • None — no ratio applied, no bars drawn. Export delivers the full frame.
  • 1.33 … 2.40 — standard delivery ratios.
  • Custom… — the dropdown shrinks to 2/3 width and a numeric input appears in the remaining 1/3. Type any ratio (e.g. 1.5). The preview updates in real time.

8. Framelines Crop & Frameline Overlay

The Frameline checkbox overlays a crop guide on the canvas. When Framelines Crop is enabled in the Resolve plugin, the still is cropped to the frameline before burn-ins are applied.

  • H 16:9 — extracts the 16:9 delivery area from the native sensor frame and upscales to 1920×1080.
  • V 9:16 — crops the centre 9:16 area from the 16:9 still (sides trimmed, no upscale). Burn-ins fill the full cropped frame.
  • Native Ratio — crops to the camera's native sensor aspect ratio and resizes to a native-ratio HD frame (e.g. Sony Venice 1 6K 3:2 → 1620×1080). Delivery bars and burn-ins are then applied on top.
  • Safety % — inset applied to the crop. Values <100% zoom in, >100% zoom out (frameline can extend beyond the canvas edge).
  • Offset X / Y — shifts the frameline relative to the image centre. Double-click X or Y to reset to 0. Double-click Frameline to reset safety to 100%.

Outside the active frameline the canvas is dimmed. Frameline colour: orange (H 16:9), blue (V 9:16), green (Native Ratio).

9. Keyboard Shortcuts

  • Cmd/Ctrl + S → Save JSON.
  • Cmd/Ctrl + Z → Undo last action.
  • Cmd/Ctrl + Y → Redo.
  • Delete / Backspace → Delete the selected token.
  • ← → ↑ ↓ → Move the selected token by 0.1%.
  • Shift + ← → ↑ ↓ → Move the selected token by 1%.
  • Escape → Close any open overlay.
