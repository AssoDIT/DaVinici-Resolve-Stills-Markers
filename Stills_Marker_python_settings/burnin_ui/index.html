User Guide – Burn-in Builder

1. Add a Burn-in

Click a metadata item in the left column to add it to the layout. It will immediately appear on the canvas and inside the "Burn-in Layout" list.

2. Selection & Movement

  • Click an element on the canvas to select it.
  • Drag it with the mouse to change its position.
  • Use Position X / Y sliders for precise adjustments.

3. Custom Template

Use the Template field to create a custom combination: %Scene / %Shot - %Take %Camera_#

Any token prefixed with % will be replaced by its value from the metadata JSON file.

4. Appearance

  • Font Size in points (pt).
  • Font selection (TTF/OTF loading supported).
  • Color, Opacity and Bold supported.

5. Keyboard Shortcuts

  • Cmd/Ctrl + S → Save JSON.
  • Cmd/Ctrl + Z → Undo last action.

6. Safe Guides

Enable guides to visualize broadcast safe margins.
